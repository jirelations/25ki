## Heutiges Lernziel

Best Practices des Programmierens mit LLMs bezüglich Datenreinigung und Datenanalyse erfassen.

## 4 Schritte

Daten müssen vorbereitet und analysiert werden. Vibe-Coding können wir in 4 Schritten machen:

1. Fragen
2. Planen
3. Programmieren
4. Testen & Erweitern

## Mögliche Prompts: Fragen

> Explain this dataset to me. What is it about, and how is it structured?

> I want to do some data analysis on XXX, answering the question YYY. For this, I need to put together some scripts to do specific analysis tasks. Help me write a plan that an AI such as Gemini or Copilot will use to build this. **Ask me the questions I need to answer to put together the plan.**

## Mögliche Prompts: Planen

> Put together a plan (specification) that an AI like Gemini or Copilot will use to clean/standardize/analyze XXX data for YYY question/result/product. It should meet the following requirements: ... It will use ZZZ technology stack. It should include documentation, and the code should run without errors. Create a step-by-step roadmap with version numbers, starting from the MVP, and adding features step by step. Tests should be built in at each stage to guarantee it runs without errors, matches the requirements, and produces the requested output.

## Mögliche Prompts: Programmieren

> Create an MVP according to this plan.

## Mögliche Prompts: Testen & Erweitern

> I got this error "XXX". Explain the error and fix it, testing to make sure it is fixed.

> Add a feature that does XXX. Test it to make sure both the earlier features and the new one still work.
